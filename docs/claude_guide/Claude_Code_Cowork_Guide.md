## Part 1: Claude Code — 너의 터미널 속 AI 개발자

### Claude Code란?

Claude Code는 터미널(CLI)에서 동작하는 AI 코딩 에이전트다. 스크린샷에서 보이듯이 너는 이미 v2.1.63이 설치되어 있고, Sonnet 4.6 모델로 구동 중이다.

핵심 콘셉트: **자연어로 말하면 Claude가 코드를 작성하고, 파일을 수정하고, 테스트하고, Git 커밋까지 한다.**

### Claude Code가 할 수 있는 일

**1. 코드 작성 & 프로젝트 생성**
```
> 자기개발 앱을 React로 만들어줘. 할 일 관리, 습관 추적, 일기 기능이 필요해.
```
Claude가 계획을 세우고 → 파일 구조를 만들고 → 코드를 작성하고 → 실행까지 처리한다.

**2. 코드베이스 분석 & 이해**
```
> 이 프로젝트의 전체 구조를 설명해줘
> payment processing 시스템이 어떻게 동작하는지 알려줘
> 사용자 권한 체크가 어디서 이뤄지는지 찾아줘
```

**3. 디버깅 & 버그 수정**
```
> 로그인 후 빈 화면이 뜨는 버그를 수정해줘
> auth 모듈 테스트를 실행하고 실패하는 것들 고쳐줘
> 이 API 엔드포인트 응답시간이 3초 이상이야. 성능 개선해줘
```

**4. Git 관리**
```
> 변경사항 커밋해줘
> PR 만들어줘
> main에 리베이스하고 충돌 해결해줘
> 12월에 markdown 테스트를 추가한 커밋이 어떤 건지 찾아줘
```

**5. 문서화 & 테스트**
```
> src/lib/의 모든 public 함수에 JSDoc 작성해줘
> 최근 10개 커밋을 분석해서 CHANGELOG 작성해줘
```

**6. 비코딩 작업 (Claude Code가 Cowork의 기반이 된 이유)**
- 파일 정리, 이름 변경, 데이터 분석
- 미디어 파일 관리
- 웹 스크래핑, 데이터 수집

### 지금 당장 해볼 수 있는 것들

**Step 1: 프로젝트 초기화**
터미널에서 프로젝트 폴더로 이동 후:
```bash
cd ~/your-project-folder
claude
```
Claude Code가 해당 폴더의 파일들을 맥락으로 인식한다.

**Step 2: CLAUDE.md 생성**
```
/init
```
이 명령으로 프로젝트 루트에 CLAUDE.md 파일이 자동 생성된다. 여기에 프로젝트 구조, 빌드 명령어, 코딩 컨벤션이 기록되어 Claude가 프로젝트를 더 잘 이해한다.

**Step 3: 주요 슬래시 명령어**

| 명령어 | 기능 |
|--------|------|
| `/init` | CLAUDE.md 생성 (프로젝트 맥락 설정) |
| `/model` | 사용 중인 모델 확인/변경 |
| `/compact` | 대화 압축 (긴 세션에서 맥락 공간 확보) |
| `/status` | 현재 설정 상태 확인 |
| `/config` | 설정 인터페이스 열기 |
| `/allowed-tools` | 허용된 도구 화이트리스트 설정 |
| `/permissions` | 자주 쓰는 bash 명령 미리 허용 |

**Step 4: 효과적인 프롬프팅**

나쁜 예:
```
> 버그 수정해줘
```

좋은 예:
```
> 사용자가 잘못된 자격 증명을 입력한 후 빈 화면을 보는 로그인 버그를 수정해줘.
> src/auth/login.ts 파일을 중심으로 확인하고, 에러 핸들링이 빠진 부분을 찾아줘.
```

**Step 5: 깊은 사고 유도**
```
> 새로운 결제 서비스를 어떻게 설계할지 think about 해줘
> 인증 플로우의 엣지 케이스에 대해 think hard 해줘
```
"think hard"라는 표현을 쓰면 Extended Thinking이 활성화되어 더 깊은 분석을 한다.

### 고급 활용: MCP 연동

MCP(Model Context Protocol)로 외부 서비스를 연결할 수 있다:
```bash
# Notion 연동
claude mcp add notion-server /path/to/notion-mcp

# Slack 연동
claude mcp add slack-server /path/to/slack-mcp

# 연결된 서버 목록 확인
claude mcp list
```

### 고급 활용: 커스텀 슬래시 명령어

자주 쓰는 작업을 명령어로 등록:
```bash
mkdir -p .claude/commands
echo "이 코드의 성능을 분석하고 3가지 최적화를 제안해줘:" > .claude/commands/optimize.md
```
이후 `/optimize`만 입력하면 해당 프롬프트가 자동 실행된다.

### 너의 상황에서 Claude Code 활용법

너는 MacBook Pro를 쓰고 있고, 1인 기업/프리랜서를 준비 중이므로:

1. **웹사이트/앱 프로토타입 빠르게 만들기**: "포트폴리오 웹사이트 만들어줘" 한마디로 시작
2. **자동화 스크립트 제작**: 반복 작업을 자동화하는 Python/Node 스크립트 생성
3. **데이터 분석**: CSV/Excel 파일을 분석하는 스크립트 생성
4. **API 연동**: 외부 서비스와 연동하는 코드 자동 생성
5. **블로그/콘텐츠 사이트**: 정적 사이트 생성기로 블로그 구축

## Part 2: Cowork — 코딩 없이 파일 작업을 자동화하는 데스크톱 에이전트

### Cowork란?

Cowork는 Claude Desktop 앱 안에서 동작하는 비코딩용 에이전트다. Claude Code와 동일한 에이전트 아키텍처를 사용하지만, 터미널 대신 데스크톱 앱의 GUI를 사용한다.

핵심 차이:
- **Claude Code** = 터미널 기반, 주로 코딩 작업
- **Cowork** = 데스크톱 앱 기반, 비코딩 지식 작업

### KAIST 폴더 접근 설정 방법 (구체적 단계)

**Step 1: Claude Desktop 앱 설치 확인**
claude.com/download에서 최신 macOS 버전을 설치한다. (너는 Mac 사용자이므로 바로 가능)

**Step 2: Cowork 모드 진입**
1. Claude Desktop 앱을 연다
2. 좌측 사이드바 또는 상단에서 **모드 선택** 클릭
3. **"Cowork"** 선택 (Chat, Code와 나란히 있다)

**Step 3: KAIST 폴더 접근 권한 부여**
1. Cowork 모드에 들어가면 **"폴더 선택"** 또는 **"+"** 버튼이 나타난다
2. 클릭하면 macOS 파인더 창이 열린다
3. `/Users/lavi/` 경로에서 **KAIST** 폴더를 선택한다
4. **"선택" 또는 "Open"** 을 클릭하면 해당 폴더가 Cowork에 마운트된다

이제 Claude는 KAIST 폴더 안의 모든 파일을 읽고, 수정하고, 새 파일을 생성할 수 있다.

**Step 4: 폴더별 지시사항 설정 (선택사항, 강력 추천)**
Settings > Cowork에서 폴더 지시사항을 설정할 수 있다:
```
이 폴더는 KAIST 관련 학습 자료, 과제, 연구 노트가 들어있습니다.
- 파일을 삭제하기 전에 반드시 확인을 받으세요
- 한국어로 응답하세요
- 파일 이름은 YYYY-MM-DD_제목 형식을 사용하세요
- 새 파일 생성 시 /output 서브폴더에 저장하세요
```

**Step 5: 전역 지시사항 설정**
Settings > Cowork > 전역 지시사항에서:
```
나는 한국어를 사용합니다.
중요한 파일 변경 전에 항상 계획을 보여주고 승인을 받으세요.
파일 삭제는 절대 자동으로 하지 마세요.
```

### Cowork 실전 활용 시나리오 (KAIST 폴더 기준)

**시나리오 1: 과제/자료 정리**
```
KAIST 폴더의 모든 파일을 스캔해서:
1. 과목별로 서브폴더를 만들어줘
2. 파일 이름을 "과목명_날짜_제목" 형식으로 통일해줘
3. 중복 파일이 있으면 리스트로 보여줘 (삭제하지 말고)
4. 정리 결과를 filing_log.txt로 만들어줘
```

**시나리오 2: 노트 종합 → 보고서 생성**
```
KAIST 폴더의 모든 txt, md 파일을 읽고:
1. 시간순으로 정렬
2. 주제별로 핵심 포인트 추출
3. 하나의 종합 요약 보고서를 Markdown으로 만들어줘
```

**시나리오 3: PDF 논문 분석**
```
KAIST/papers 폴더의 PDF들을 읽고:
1. 각 논문의 제목, 저자, 핵심 주장을 추출
2. 공통 주제와 차이점을 분석
3. 참고문헌 리스트를 APA 형식으로 정리
4. 종합 리뷰 문서를 생성해줘
```

**시나리오 4: 영수증 → 경비 보고서**
```
KAIST/receipts 폴더의 이미지들을 읽고:
1. 각 영수증에서 날짜, 매장명, 금액 추출
2. Excel 스프레드시트 생성
3. 카테고리별(교통비, 식비, 도서비 등) 합계 포함
```

### 보안 주의사항

- Cowork는 **격리된 가상 머신(VM)** 안에서 실행된다
- 그러나 **마운트한 폴더 안의 파일은 실제로 수정/삭제 가능**하다
- 비밀번호, 재무 기록 등 민감한 파일이 있는 폴더는 마운트하지 않는 것이 좋다
- **처음에는 테스트 폴더로 먼저 연습**하는 것을 추천
- 중요한 파일은 **백업 후** Cowork에 맡길 것

### 네트워크 접근 설정

Cowork가 웹사이트에 접근해야 하는 경우 (예: 리서치 작업):
- Settings에서 **도메인 접근 허가**를 설정해야 한다
- Claude in Chrome 확장 프로그램을 연동하면 브라우저 자동화도 가능

## Part 3: Claude Code vs Cowork — 언제 뭘 쓸까

| 상황 | Claude Code | Cowork |
|------|-------------|--------|
| 웹앱/서비스 개발 | ✅ 최적 | — |
| 파일 정리/분류 | 가능하지만 번거로움 | ✅ 최적 |
| 자동화 스크립트 작성 | ✅ 최적 | — |
| 보고서 생성 | 가능 | ✅ 최적 |
| Git 작업 | ✅ 최적 | — |
| 데이터 분석 | ✅ 코드 기반 | ✅ 파일 기반 |
| 영수증/문서 처리 | 가능 | ✅ 최적 |
| 웹 리서치 | 제한적 | ✅ Chrome 연동 |
| 코드 리뷰/디버깅 | ✅ 최적 | — |
| 반복 예약 작업 | cron 설정 필요 | ✅ 내장 기능 |

## Part 4: 요금제 참고

너는 현재 **Claude Pro** 플랜($20/월)을 사용 중이다.

- **Claude Code**: Pro 이상에서 사용 가능. 단, 사용량 50%까지 Opus 4.6, 나머지는 Sonnet 사용.
- **Cowork**: Pro에서 사용 가능하나, 토큰 소모가 빠름. 헤비 유저라면 Max($100/월) 고려.
- **Max 5x ($100/월)**: 5시간마다 약 225개 메시지. Cowork를 본격적으로 쓸 때 적합.
