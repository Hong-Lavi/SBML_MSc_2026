# Claude 활용 최적화 가이드

---

## 1. Cowork란 무엇인가?

Cowork는 2026년 1월에 출시된 Anthropic의 데스크톱 에이전트 도구로, **Claude Code의 파워를 비개발자도 쓸 수 있게** 만든 제품이다. 현재 Windows와 macOS 모두 지원하며, 유료 플랜(Pro $20/월 이상)에서 사용 가능하다.

### 핵심 기능

- **로컬 파일 접근**: 지정한 폴더 내 파일을 읽고, 수정하고, 생성할 수 있다
- **멀티스텝 작업 실행**: "이 5개 회사 경쟁 분석 보고서 만들어줘"라고 하면, 리서치 → 요약 → 포맷팅 → 산출까지 알아서 쪼개서 실행한다
- **커넥터**: Slack, Notion, Figma, Google Drive, Gmail, DocuSign 등 외부 서비스와 연동
- **Chrome 연동**: 웹 브라우징, 폼 작성, 데이터 수집을 브라우저를 통해 수행
- **글로벌/폴더별 지시사항**: 선호하는 톤, 포맷, 역할 배경 등을 설정하면 모든 세션에 자동 적용
- **예약 작업**: 일간/주간/월간으로 반복 작업을 설정해 자동 실행

### 일반 채팅과의 차이점

일반 채팅에서 Claude는 **텍스트를 주고받을 뿐** 실제 파일을 건드리지 못한다. Cowork에서는 Claude가 **직접 파일을 만들고, 수정하고, 정리**할 수 있다. 즉 "방법을 설명하는 것"이 아니라 "직접 실행하는 것"이 핵심 차이다.

### 너의 상황에서 Cowork 활용 방안

너는 **1인 기업/프리랜서로서 AI를 두뇌+손발로 활용**하려는 사람이니까, Cowork는 다음과 같이 쓸 수 있다:

1. **자료 정리 자동화**: 스크린샷 영수증들로부터 경비 스프레드시트 자동 생성
2. **리서치 → 보고서**: 흩어진 노트들을 모아 초안 보고서 작성
3. **파일 관리**: 다운로드 폴더 자동 분류, 리네이밍
4. **반복 업무 자동화**: 주간 보고서, 일일 요약 등을 예약 실행
5. **프로젝트별 워크플로우**: 폴더별 지시사항으로 프로젝트마다 다른 맥락 유지

## 2. Claude의 사용자 정보 저장 시스템

Claude에는 **3가지 레벨**의 개인화 시스템이 있다:

### ① Profile Preferences (프로필 환경설정) — 모든 대화에 적용

**접근 방법:**
1. claude.ai 접속
2. 좌측 하단의 **본인 이니셜(또는 프로필 아이콘)** 클릭
3. **Settings** 선택
4. **"User Preferences"** 또는 **"Profile"** 항목에서 작성

여기에 작성하는 내용은 **새로운 채팅을 열 때마다 자동으로** Claude에게 전달된다.

### ② Project Instructions (프로젝트 지시사항) — 특정 프로젝트에만 적용

특정 프로젝트를 만들고 그 안에서 나누는 대화에만 적용되는 맥락 정보. 프로젝트별로 다른 역할/톤/배경을 설정할 수 있다.

### ③ Styles (스타일) — 응답 방식 커스터마이징

Claude의 말투, 길이, 포맷을 조절한다. Concise, Explanatory 등 프리셋이 있고, 커스텀 스타일도 만들 수 있다.

### ④ Memory (메모리) — 대화 간 기억 유지

Settings에서 Memory 기능을 활성화하면, Claude가 이전 대화에서 파악한 정보를 기억하고 다른 대화에서도 참조할 수 있다. **현재 너는 이 기능이 비활성화 상태**이므로, Settings에서 켜는 것을 강력히 추천한다.

- 현재 GPT(손발 역할)와 Claude(두뇌 역할)를 분리해서 활용하는 전략을 구축 중

## 4. Claude를 "나의 두뇌"로 최적화하는 사용법

### 기본 원칙: Claude는 대화형 도구다

Claude는 한 번 프롬프트를 던지고 끝나는 게 아니라, **대화를 통해 사고를 심화**시킬 때 가장 강력하다.

### 실전 사용 패턴

#### 패턴 1: 전략 수립 (브레인스토밍 → 구조화)
```
"나는 [X]를 하려고 해. 이 아이디어의 실행 가능성을 분석해주고, 
내가 고려해야 할 리스크 3가지와 대안을 제시해줘."
```
→ 이후 Claude의 답변에 대해 "두 번째 리스크에 대해 더 깊이 파고들어줘" 식으로 심화

#### 패턴 2: 의사결정 프레임워크
```
"A와 B 중 선택해야 해. 각각의 장단점을 비교해주고, 
나의 상황(1인 기업 준비, 제한된 자본)을 고려한 추천을 해줘."
```

#### 패턴 3: 프로젝트 관리 (장기 대화)
하나의 프로젝트에 대해 **하나의 대화를 유지**하면서 진행 상황을 업데이트하면, Claude가 맥락을 유지한 상태로 조언할 수 있다. 프로젝트가 여러 개면 **Projects 기능**을 활용해 각각 별도 공간에서 관리.

#### 패턴 4: 리서치 + 종합
```
"[주제]에 대해 최신 정보를 검색해서 정리해줘. 
특히 [관점]에서 분석하고, 내 상황에 적용할 수 있는 액션 아이템을 뽑아줘."
```

#### 패턴 5: 문서/산출물 생성
```
"지금까지 논의한 내용을 바탕으로 [보고서/계획서/스프레드시트]를 만들어줘."
```
→ Claude.ai의 파일 생성 기능으로 docx, pptx, xlsx 등 직접 생성 가능

### 효율을 높이는 습관

1. **Memory 기능 반드시 켜기**: Settings에서 활성화하면 대화 간 맥락이 유지됨
2. **User Preferences 주기적 업데이트**: 새 프로젝트를 시작하거나 방향이 바뀌면 반영
3. **프로젝트별 대화 분리**: Projects 기능으로 주제별 채팅 관리
4. **GPT와의 역할 분리 유지**:
   - Claude = 분석, 전략, 사고, 계획, 리서치 종합
   - GPT = 실행, 자동화, 반복 작업, API 연동
5. **Cowork 활용**: 파일 작업, 정리, 반복 업무는 Cowork에 위임
6. **Claude in Chrome**: 웹 리서치나 폼 작성 등 브라우저 기반 작업에 활용

### Claude vs GPT 역할 분담 요약

| 영역 | Claude (두뇌) | GPT (손발) |
|------|--------------|-----------|
| 전략 수립 | ✅ 핵심 | 보조 |
| 분석/비교 | ✅ 핵심 | 보조 |
| 리서치 종합 | ✅ 핵심 | 데이터 수집 |
| 문서 작성 | ✅ 초안/구조 | 대량 생산 |
| 코딩/자동화 | 설계/리뷰 | ✅ 실행 |
| 반복 작업 | 위임 | ✅ 핵심 |
| 의사결정 | ✅ 핵심 | 참고용 |

## 5. 즉시 실행할 체크리스트

- [ ] **Settings → Memory 기능 활성화**
- [ ] **Settings → User Preferences에 위 프롬프트 붙여넣기**
- [ ] **Claude Desktop 앱 설치** (Cowork 사용을 위해)
- [ ] **Cowork에서 작업 폴더 지정하고 첫 작업 시도** (다운로드 폴더 정리 추천)
- [ ] **주요 프로젝트별 Project 생성** (claude.ai에서)
- [ ] **Claude in Chrome 확장 프로그램 설치** (브라우저 자동화용)
